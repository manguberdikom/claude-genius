# 8-vazifa oltin javobi (baholovchi kalibrlash uchun)

Diffni to'xtataman: to'rtta nuqson bor.

1. `SEARCH_CACHE` static `HashMap`, controller esa hamma so'rovga bitta.
   `HashMap` thread-safe emas: parallel so'rovlarda ichki holat buziladi,
   yo'qolgan yozuv yoki cheksiz sikl bo'lishi mumkin. Kerak bo'lsa
   `ConcurrentHashMap` yoki Spring `@Cacheable` bilan tayyor kesh.
2. Kesh cheklanmagan: na hajm chegarasi, na TTL. Har yangi familiya va
   sahifa yozuv qo'shadi, xotira o'sadi va oxiri OOM. Caffeine
   `maximumSize` va `expireAfterWrite` bilan cheklash kerak.
3. `catch (Exception e) { e.printStackTrace(); return Page.empty(); }`
   xatoni yutib yuboradi: baza yiqilsa foydalanuvchi "topilmadi" degan
   yolg'on javob oladi, log esa stdout ga ketadi.
4. Invalidatsiya yo'q: ega qo'shilgan yoki yangilangandan keyin ham eski
   sahifa qaytadi (stale ma'lumot). Yozuvda `@CacheEvict` kerak.
