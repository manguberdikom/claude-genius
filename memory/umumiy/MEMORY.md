# Umumiy memory

Barcha proyektlarga tegishli yozuvlar. Bitta yozuv bitta qator.

- `user_til-va-uslub.md` - javob va hujjat tili, yozuv uslubi, hisobot shakli
- `feedback_birlashtirish-commit.md` - guruh birlashtirgandan keyin commit tuzog'i, ko'p qatorli commit xabari
- `feedback_startup-xatosini-tuzatish.md` - startup xatosida to'liq trace, himoya emas xato yo'lini olib tashlash, bean o'zgarishida testni tur bo'yicha qidirish, muzlatilgan migratsiya izohi
- `feedback_pdf-vizual-tekshiruv.md` - chizilgan hujjat ko'rinishi o'zgarganda vaqtinchalik test bilan PNG ga render qilib ko'z bilan tekshirish
- `feedback_golden-update-begona-snapshot.md` - golden yangilash rejimi begona snapshotlarni ham qayta yozadi, kutilgan ro'yxat bilan solishtirish
- `feedback_klon-faqat-main.md` - klonda faqat `main`: boshqa branch ochilmaydi, saboq commiti `main` ga push qilinadi
- `feedback_mdc-korrelyatsiya-id-bosilishi.md` - filtr qo'ygan MDC korrelyatsiya id ni kutubxona interceptor i bosib ketadi
- `feedback_kontrakt-parity-oram.md` - shakl pariteti tekshirilganda javob o'ramini ham solishtirish, kontrakt testi JSON yo'lini ildizdan yozishi
- `feedback_sheets-sintetik-paste.md` - Google Sheets ga brauzerdan ko'p qator yozish: sintetik paste hodisasi, koordinata masshtabi
- `feedback_umumiy-daraxt-kompilyatsiya-buzilgan.md` - boshqa sessiyaning yarim ishi umumiy daraxtni yig'ilmas qilsa, testni ajratilgan worktree da yurgizish
